# STA2002 · Sign Test & Wilcoxon Signed-Rank Test

Interactive lecture slides for distribution-free tests of a population median.

Live: https://kwtsang101016.github.io/sta2002/sign-wilcoxon/

## Topics

- Sign test for $H_0:m=m_0$ with $W\sim\mathrm{Bin}(n,1/2)$
- Type I error / critical regions for two-sided sign tests
- Wilcoxon signed-rank statistic (signs × ranks)
- Null distribution via independent signed ranks and normal approximation
- Whole-unit continuity correction
- Handling ties ($x_k=m_0$ and tied absolute differences)
