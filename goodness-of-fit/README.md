# STA2002 · Goodness-of-fit Test

Interactive lecture slides for Pearson’s chi-square goodness-of-fit test.

Live: https://kwtsang101016.github.io/sta2002/goodness-of-fit/

## Topics

- Pearson’s chi-square statistic and the multinomial model
- Null approximation $\chi^2(k-1)$ when cell expectations are at least 5
- Fair-die and binomial examples
- Continuous distributions via bins, including combining sparse cells
- Unknown parameters: MLE and degrees of freedom $k-1-d$
