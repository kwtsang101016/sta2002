# STA2002 · Contingency Tables

Interactive lecture slides for chi-square tests of homogeneity and independence.

Live: https://kwtsang101016.github.io/sta2002/contingency-table/

## Topics

- Contingency tables and expected cell frequencies
- Test for homogeneity of several multinomial distributions
- Test for independence of two categorical attributes
- Degrees of freedom $(k-1)(h-1)$ and the shared Pearson statistic
- Worked $2\times 2$, $3\times 3$, and $2\times 5$ examples

## Local development

```bash
npm install
npm run dev
```
