# STA2002 · Hypothesis Testing (interactive lecture)

Based on Lecture 6–9 (concepts and one mean, two means and variances, proportions, power and sample size).

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5178/

## Topics

- Hypotheses, critical regions, Type I/II errors, significance level, p-values
- z and t tests for one normal mean
- Pooled, Welch, and paired t-tests; F-test for two variances
- Tests for one proportion and for p1 − p2
- Power functions and sample size for means and a binomial test

## Games

- Steel-bar cutoff explorer (α vs β)
- Power explorer for an upper-tailed z test
- One-proportion z test calculator
