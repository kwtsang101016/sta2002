# STA2002 · Parameter Estimation

Interactive lecture slides covering **Parameter Estimation I & II** (EDA, MLE, unbiasedness, method of moments), based on Fangda Song / Ka Wai Tseng Lec2–Lec3 materials.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5176

## Contents

- Histograms & boxplots
- University of Miami COVID-19 case study (`public/data/UM_C19_2021.csv`)
- Likelihood / MLE (Bernoulli, Exponential, Geometric, Uniform, Normal)
- Unbiasedness and bias of the normal variance MLE
- Method of moments (Gamma, Poisson, Uniform)
- Interactive games: COVID EDA, prediction calculator, Bernoulli ℓ(p), bias demo, Poisson MoM simulation, Uniform MLE vs MoM
