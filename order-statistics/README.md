# STA2002 · Order Statistics (interactive lecture)

Based on `Lecture notes/Order Statistics/Lecture10.tex`.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5180/

## Topics

- Definition of order statistics \(X_{(k)}\)
- CDF / PDF of \(X_{(k)}\) (binomial counting argument)
- Uniform\((0,1)\) order statistics and the Beta distribution
- Probability integral transform: \(F(X_i)\sim U(0,1)\), \(F(X_{(k)})\sim\mathrm{Beta}(k,n-k+1)\)
