# STA2002 · One-way ANOVA

Interactive lecture slides for one-way analysis of variance and the $F$ test.

Live: https://kwtsang101016.github.io/sta2002/one-way-anova/

## Topics

- Comparing $m$ normal means with common variance
- Total, treatment, and error sums of squares
- Mean squares and the ANOVA $F$ statistic
- Decision rule with $F(m-1,n-m)$
- Worked pullout-force example

## Local development

```bash
npm install
npm run dev
```
