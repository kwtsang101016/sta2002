# STA2002 · Quantiles and Q-Q Plots (interactive lecture)

Based on `Lecture notes/Quantiles and Q-Q plots/Lec11/Lecture11.tex`.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5181/

## Topics

- Theoretical $p$-th quantile / percentile
- Normal quantiles $\pi_p=\mu+\sigma z_{1-p}$
- Sample quantiles via order statistics and linear interpolation
- Bias of the sample median (Exp example)
- Q-Q plots as a visual check of a distributional assumption
