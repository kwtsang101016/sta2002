# STA2002 · Confidence Intervals (interactive lecture)

Based on Lecture4 (CI for means) and Lecture5 (two means, proportions, sample size).

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5177/

## Topics

- Definition of a confidence interval
- Four cases for μ (z / t, σ known / unknown)
- One-sided intervals
- Pooled, Welch, and paired t-intervals
- CIs for proportions and differences of proportions
- Sample size for a target margin of error

## Games

- z-interval explorer
- Coverage simulator (many random CIs, normal parent)
- **CLT coverage explorer** (tune \(n\) and skewness; same \(z\)-interval, Case 1 vs 2 reliability)
- z vs t critical values
- Pooled / Welch / paired width comparison
- Proportion CI calculator
- Sample size planner
